## 4. うまくいかないときの切り分け

| 症状 | 確認すること |
|---|---|
| Cloud Build が始まらない | GitHubのトリガーが `main` に紐づいているか。push先のブランチが `main` か |
| ビルドが失敗する | Cloud Build のログを開き、失敗したステップ（build / push-sha / deploy）を特定する。今回はPHP/JSONの変更のみなので、JSONの構文エラーは考えにくい（書き出し前に `json.loads` で検証済み） |
| ビルドは成功したが版数が0263のまま | ブラウザキャッシュ。`?cb=` を付けて再確認。それでも古い場合は Cloud Run のリビジョンが切り替わっているかコンソールで確認 |
| 記事が1件も増えていない | `data/blog-posts.json` がコミットに含まれていたか `git show --stat HEAD` で確認 |
| 一部の記事だけ出ない | `published` が true か、`date` の形式が `YYYY-MM-DD` か（24件すべて検証済み） |
