## 2. ⚠ リポジトリへの書き込みが2回、取り消されています

| 回 | 内容 | 書き込み後の状態 | 次に確認したときの状態 |
|---|---|---|---|
| 1回目 | フッターボタン（v1502） | `index.php` 54,401B ／ `script.js` 7,867B | **54,250B ／ 7,335B（v1501に戻る）** |
| 2回目 | noindex（v1503） | `index.php` 54,379B | **54,401B（v1502に戻る）** |

**パターンが一貫しています。** 「直前に書き込んだ変更だけが、次の操作で1段階前に戻る」動きです。
`styles.css` は両回とも巻き戻っていません。

### 考えられる原因（すべて**未確認**）

- GitHub Desktop の「変更を破棄（Discard changes）」
- `git checkout -- lp1/` / `git restore lp1/`
- Codex が自分の作業ツリーの内容で書き戻している
- 複数の作業者・ツールが同じフォルダを同時に触っている

### 確認のお願い

Windows機で次を実行し、結果を教えてください。原因の切り分けができます。

```powershell
cd D:\__github_win\en-lp\push\en-lp
git --no-optional-locks status --short
git log --oneline -8
git reflog -15
```

`git reflog` に `checkout` や `reset` の記録があれば、git 操作が原因と特定できます。

## 3. 今の状態（3回目の書き込み済み）

`lp1/index.php` `lp1/script.js` `lp1/styles.css` を **v2026091503** にしました。
内容は noindex ＋ フッターボタン ＋ 計測です。

**次に git 操作をする前に、まずこの3ファイルを commit してください。**
巻き戻りは「書き込み → 次の操作」の間に起きているため、**先に commit すれば固定できます。**

```powershell
cd D:\__github_win\en-lp\push\en-lp
git --no-optional-locks status --short
git add lp1/index.php lp1/script.js lp1/styles.css
git commit -m "lp1: 広告専用化(noindex,follow)・フッター公式サイト導線 (LP v2026091503)"
git push origin main
```

commit 前に `git status` で **3ファイルが変更として見えているか**を確認してください。
見えていなければ、その時点でまた巻き戻っています。
