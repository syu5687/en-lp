# 追補：GBPからのクリックはGA4で分かるか

## 結論：**いまのままでは分かりません。** UTMを付ければ分かります

### 現状（実測）

GBPの「ウェブサイト」ボタンのリンク先は **`https://en1150.co.jp/kaiyou-sou/`**（UTMなし）です。
リンク先自体はMEOの定石どおりで、トップ一律ではなくサービスページに向いています。ここは適切です。

ただし**UTMが付いていないため、GA4では通常の自然検索（google / organic）に混ざります。**
「この問い合わせはGBP経由だった」という切り分けができません。

---

## 対応：UTMを付ける

### 推奨するパラメータ

```
https://en1150.co.jp/kaiyou-sou/?utm_source=google&utm_medium=organic&utm_campaign=gbp_kagoshima
```

**`utm_medium` を `organic` のままにするのが肝**です。理由は2つあります。

| | |
|---|---|
| チャネルが変わらない | GA4は `source=google` + `medium=organic` を「Organic Search」と判定します。**過去との比較が壊れません** |
| それでも切り分けられる | 「セッションのキャンペーン」に `gbp_kagoshima` が入るので、GBP経由だけを抽出できます |

⚠ `utm_medium=gbp` のような独自の値を入れると、GA4のデフォルトチャネルグループで
**「Unassigned」**に落ちてしまい、かえって見づらくなります。

### 投稿（最新情報）のリンクにも別のUTMを

投稿ごとにキャンペーン名を分けると、どの投稿が効いたかが分かります。

| 投稿 | リンク |
|---|---|
| 第1回（10/24告知・投稿済み） | `.../kaiyou-sou/#goudou-schedule?utm_source=google&utm_medium=organic&utm_campaign=gbp_post_20260915` |
| 第2回（プランの違い） | `.../kaiyou-sou/?utm_source=google&utm_medium=organic&utm_campaign=gbp_post_20260922` |
| 第3回（証明書・六価クロム） | `.../kaiyou-sou/?utm_source=google&utm_medium=organic&utm_campaign=gbp_post_20260929` |
| 第4回（墓じまい） | `.../grave/?utm_source=google&utm_medium=organic&utm_campaign=gbp_post_20261006` |

※ アンカー（`#goudou-schedule`）を使う場合、**クエリはアンカーより前**に置きます。
`.../kaiyou-sou/?utm_...=...#goudou-schedule` が正しい順序です。

---

## GA4での見方

**レポート → 集客 → トラフィック獲得** で、ディメンションを「**セッションのキャンペーン**」に変更。
`gbp_kagoshima` と `gbp_post_*` が並びます。

そこに、v0263で入れた `contact_submit`・`tel_click`・`line_click` を重ねれば、
**GBP経由で何件の問い合わせが発生したか**まで追えます。

---

## GA4だけでは分からないもの（GBP側で見る）

| 指標 | GA4 | GBPパフォーマンス |
|---|---|---|
| ウェブサイトのクリック | UTMを付ければ可 | 取れる |
| **電話タップ** | **取れません** | 取れる |
| **ルート案内のリクエスト** | **取れません** | 取れる |
| **マップ／検索での表示回数** | **取れません** | 取れる |
| **どんな検索語で見つかったか** | 取れません | 取れる |
| 問い合わせ送信（CV） | 取れる | 取れません |

GBPの電話タップは、サイトを経由せず直接発信されるため**GA4には一切届きません。**
つまり**両方を見ないと全体像になりません。** 月次レポートには両方を載せます。

---

## 数値は一致しません

GBPの「ウェブサイトのクリック数」と、GA4のセッション数は**必ずズレます**。
リダイレクト経由・計測ブロック・ボット・離脱などが理由です。
**GBPの方が多く出るのが普通**です。どちらが正しいかを争わず、それぞれの推移を見ます。
