## 2. 前回の判断が誤っていた理由

**「noindex だから自然流入を送らない」という理屈は、ここでは成り立ちません。**

`noindex` は**検索エンジンに対して「このページを検索結果に載せないでください」と伝える指示**です。
人がリンクをクリックして訪問することとは、まったく無関係です。

GBP投稿のリンクは**人が踏むもの**なので、noindex であっても普通に表示され、普通に使えます。
「広告専用」という呼び方に引きずられて、機械向けの設定を人の動線にまで当てはめていました。

## 3. `/lp1/` のほうが良い理由

### 【事実】2ページの構造の違い（実測）

| | `/lp1/` | `/kaiyou-sou/` |
|---|---|---|
| ページ高さ | — | **17,027px** |
| 合同散骨の日程の位置 | ファーストビュー直下 | **10,319px（約6割下）** |
| フォーム | **ページ内にあり**（送信までページ内で完結） | `/contact/` へ移動が必要 |
| スマホ固定CTA | あり（電話／LINE） | あり（floating-cta） |
| 構成 | 1枚完結（読む→決める→送る） | 回遊型（他ページへ誘導） |

### 【データ】GBPからの訪問者の性質

GBPの投稿を開く人は、**地図やGoogle検索でこの会社を見つけ、内容を読んだうえでクリック**しています。
すでに「この会社でいいか」を判断する段階に入っています。

9/7の分析でも、「業者／おすすめ／選び方」といった比較検討の語は
滞在206秒・PV1.90と、全キーワード中もっとも濃い層でした。GBP経由はこれに近い性質です。

### 【仮説】

比較検討段階の人を、日程が6割下にある17,027pxの回遊型ページに送ると、
**たどり着く前に離脱します**。`/lp1/` なら読む・決める・送るが1ページで終わります。

### 【変更内容】

第1〜3回の投稿リンクを `/lp1/` に変更し、`utm_campaign` で広告流入と分離します。

```
https://en1150.co.jp/lp1/?utm_source=google&utm_medium=organic&utm_campaign=gbp_post_20260922
```

### 【期待効果】

GBP経由の問い合わせ増。`contact_submit` と `gclid`/`utm` の保存が `/lp1/` には入っているため、
**何件がGBP経由だったかを実データで確認できます**（`/kaiyou-sou/` 経由より計測が精緻です）。

### 【リスク】と、その打ち消し方

| 懸念 | 実際のところ |
|---|---|
| 広告のCPA・CVRにGBP流入が混ざる | **混ざりません。** Google広告の管理画面は「広告クリック起点」のみを集計します |
| GA4でLPの評価が濁る | `utm_campaign` が `gbp_post_*` なので**除外して集計できます**。広告分は `gclid` の有無でも分かります |
| noindexページに人を送ってよいのか | 人の閲覧には影響しません。※GBPのポリシー上の可否は**未確認**ですが、リンク先の要件は「ビジネスに関連する有効なページ」であり、抵触する記述は見当たりません |
| SEO資産にならない | GBP投稿のリンクは元々SEO評価を渡しません。`/kaiyou-sou/` に送っても同じです |

### 【確認KPI】

GA4「セッションのキャンペーン」で `gbp_post_*` を絞り、
`contact_submit` / `tel_click` / `line_click` の件数と、`/kaiyou-sou/` 経由だった時期との比較。

## 4. 「ウェブサイト」ボタンは変えません

投稿リンクと違い、**GBPの「ウェブサイト」ボタンは会社の公式サイトを示す欄**です。
Googleがビジネスの実在性や情報の整合性を照合する際にも参照します。

ここに noindex のページを指定すると、Googleがビジネス情報を照合できない可能性があります
（**未確認**ですが、確認できない以上リスクを取る必要はありません）。

`/kaiyou-sou/` は鹿児島の海洋散骨のサービスページで、MEOの定石（トップ一律にせずサービスページへ）にも合っています。**変更しません。**

> **投稿リンク＝行動させる動線 → `/lp1/`**
> **ウェブサイトボタン＝会社の正面 → `/kaiyou-sou/`**

この使い分けです。

## 5. 第4回（墓じまい）を `/lp1/` にしない理由

`/lp1/` は**鹿児島の海洋散骨に特化**したLPです。墓じまいの情報はありません。
墓じまいを調べて開いた人を海洋散骨のLPに送ると、9/7に指摘した
「福岡の検索者を鹿児島LPに送っている」のと同じ取りこぼしが起きます。

第4回は `/grave/` のままにします。
