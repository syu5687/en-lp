## 1. 追加したもの

フッター右カラム、「山野石材は提携・協力先です」の下・会社情報リンクの上に、囲み罫のボタンを1つ置きました。

```html
<a class="footer-official" id="lp-official-link" href="https://en1150.co.jp/">
  有限会社 縁 公式サイト<span aria-hidden="true">〉</span>
</a>
```

- ラベルは **「有限会社 縁 公式サイト」**。「公式サイトを見る」だけだと何のサイトか分からないため、社名を入れています
- リンク先はトップ `https://en1150.co.jp/`
- **同じタブで開きます**（同一ドメインのため。別タブにする案は3章）
- `〉` は装飾ではなく方向の合図なので `aria-hidden="true"`。読み上げでは「有限会社 縁 公式サイト」とだけ読まれます

### 見た目

フッターは濃紺地のため、塗りボタンではなく**白の細い囲み罫**にしました。既存の `.outline`（明るい背景用）と同じ考え方で、装飾を足していません。

```css
.footer-official{
  display:inline-flex;align-items:center;justify-content:space-between;gap:16px;
  margin-top:22px;padding:13px 22px;
  border:1px solid rgba(255,255,255,.5);border-radius:4px;
  font-size:14px;letter-spacing:.06em;color:#fff
}
.footer-official span{font-size:12px;opacity:.75}
```

スマホ（540px以下）は横幅いっぱい・`padding:14px 18px` で、タップ領域を約50px高さに確保しています。

### 表示確認（実測）

ローカルで PC 1280px ／ SP 390px の2幅をレンダリングして確認しました。

- PC：文字幅に合わせた横長ボタン。会社情報リンクとの間隔も詰まっていません
- SP：横幅いっぱい。文字の折り返し・はみ出しなし
- SP のフッターは `padding-bottom:70px` があるため、**画面下の固定CTA（`.mobile-cta`）に隠れません**

## 2. クリックの計測

このボタンだけ、クリックを GA4 に送るようにしました。

```js
gtag('event', 'outbound_internal', {
  link_url: 'https://en1150.co.jp/',
  link_label: '公式サイト（フッター）',
  page_path: '/lp1/'
});
```

イベント名 `outbound_internal` は、運用方法レポート【A-2】で計画した「LP内の外部リンク12本の離脱計測」と同じ名前です。
今回はフッターの1本だけに付けています。**既存のイベント名は一切変更していません。**

LPからどれだけ公式サイトへ抜けているかが分かるので、あとで「この導線は残すか・位置を変えるか」をデータで判断できます。

⚠ 計測不要であれば、`lp1/script.js` の該当ブロック（`lp-official-link` の addEventListener）を削除してください。ボタン自体はそのまま動きます。

## 3. 判断が要る点：同じタブか、別タブか

| | 同じタブ（**現在の実装**） | 別タブ（`target="_blank"`） |
|---|---|---|
| 利点 | 同一ドメイン内の移動として自然。ブラウザの戻るで帰れる | LPが開いたまま残る |
| 欠点 | LPから離脱する | 同一サイト内で別タブが開くのは、人によっては不意打ちに感じる |

LPは広告の受け皿なので「LPを残したい」という考え方もあります。
**別タブにする場合**は `target="_blank" rel="noopener"` を足すだけです。ご指示ください。

## 6. ダメ出し検証

| 視点 | 想定される失敗 | 対策 |
|---|---|---|
| 広告担当 | 公式サイトへの導線を増やしたぶん、LPからの離脱が増えてCVが落ちる | フッター＝最後まで読んだ人が到達する位置なので、フォームを飛ばして抜ける導線にはなりにくい。ただし2章の計測で実数を見て判断する |
| 初見ユーザー | 「公式サイト」と書かれると、LPが公式でないように見える | LPも同じ `en1150.co.jp` のページです。気になる場合はラベルを「会社の公式サイトへ」「サービス全体を見る」等に変更できます |
| デザイン | フッターのリンクが増えて散らかる | 囲み罫のボタン1つに限定し、既存の会社情報リンク（3本）の上に置いて役割を分けています |
| SEO | LPを `noindex` にした場合、このリンクの評価が渡らない | `noindex,follow` にすればリンクは辿られます（運用方法レポート S-1 の案1が `follow` を残しているのはこのためです） |
| アクセシビリティ | `〉` が読み上げられて意味不明になる | `aria-hidden="true"` 済み |

### リンク先をトップにした理由

LPの読者は「鹿児島の海洋散骨」で来た人です。フッターまで読んだ時点で残る関心は
「この会社は他に何をしているのか」「どんな会社なのか」で、`/service/` のような1階層下より
トップの方が受け止められる幅が広くなります。

将来、公式サイト側で見せたい導線が固まったら、リンク先だけ差し替えれば済みます（`lp1/index.php` の1行）。
