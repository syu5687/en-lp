## 1. `/lp1/` を noindex にしました

```html
<!-- 変更前 -->
<meta name="robots" content="index,follow,max-image-preview:large">
<!-- 変更後 -->
<meta name="robots" content="noindex,follow">
```

### `follow` を残した理由

`noindex,nofollow` にすると、LPから公式サイト各ページ（`/kaiyou-sou/` `/powder-cleaning/` `/teraumi/`
`/staff/` `/voice/` `/company/` 、今回のフッターボタンを含む12本）へのリンク評価がすべて止まります。
`follow` を残せば、LP自体は検索結果に出ないまま、リンク先の評価は通常どおり渡ります。

### 副作用チェック（すべて実測・問題なし）

| 確認項目 | 結果 |
|---|---|
| `robots.txt` が `/lp1/` をブロックしていないか | **ブロックしていません**（`Allow: /`）。クロールできるので noindex が正しく読まれます |
| `sitemap.php` に `/lp1/` が入っていないか | **入っていません**。noindex と矛盾しません |
| `llms.txt` に `/lp1/` の記載がないか | **ありません** |
| 広告の審査クロールへの影響 | **ありません**。noindex は「インデックスしない」であってクロール拒否ではないため、AdsBot はアクセスできます |
| 品質スコア／ランディングページ体験への影響 | noindex とは無関係です |

Search Console では `/lp1/` が「除外 — noindex タグによって除外されました」に入りますが、**これが正常な状態**です。

### 元に戻すとき

`lp1/index.php` の1行を `index,follow,max-image-preview:large` に戻すだけです。**可逆です。**

## 3. 広告の最終URL切替 — 実行順序が重要です

### ⚠ 順序：**デプロイ →（動作確認）→ 広告切替**

先に広告を `/lp1/` に向けると、`contact_submit` がまだ本番に無いため、
**LPで発生したCVを正しい指標で数えられません。** `generate_lead`（8月261件・スパム疑い）に混ざります。

| 順 | 内容 |
|---|---|
| 1 | v0263 を commit & push（Cloud Build 完了まで待つ） |
| 2 | `npx wrangler deploy`（Worker） |
| 3 | 本番確認（`?cb=v2026091503`／noindex／日程／フッターボタン） |
| 4 | テスト送信1件（`mk@lu-m.co.jp`・【テスト送信】明記） |
| 5 | **切替前のベースラインを記録**（下記4章） |
| 6 | 広告の最終URLを `/lp1/` へ変更 |

### 3-1. まず、アドブロッカーの解除が必要です

前回 Google広告の管理画面を開いたところ、「Turn off ad blockers」が表示され、
**キャンペーン表のデータ行が描画されませんでした**（12キャンペーン存在することのみ確認）。

`ads.google.com` に対して拡張機能を無効化していただければ、こちらで操作できます。
ご自身で操作される場合は、下の手順をそのまま実施してください。

### 3-2. 対象の特定（**未確認**）

「鹿児島・海洋葬関連」がどのキャンペーン／広告グループを指すかは、管理画面が読めていないため**未確認**です。
以下の条件で拾ってください。

- キャンペーン名・広告グループ名に「鹿児島」「海洋散骨」「海洋葬」「散骨」を含むもの
- 現在の最終URLが `/kaiyou-sou/`（鹿児島版）になっているもの

**除外するもの（切り替えない）**

| 対象 | 理由 |
|---|---|
| 福岡系（`/kaiyou-sou/fukuoka/` `/fukuoka/` 着地） | `/lp1/` は鹿児島専用。福岡の検索者を鹿児島LPに送ると9/7と同じ取りこぼしが再発します |
| 墓じまい系（`/grave/` `/grave/fukuoka/`） | サービスが違います |
| 粉骨系（`/powder-cleaning/` `/powder/`） | 同上 |
| 全国・地域指定なしのキャンペーン | `/lp1/` は鹿児島の出航地・海域を前提にした内容です |

### 3-3. 変更する箇所

最終URLは **キャンペーン・広告グループ・広告・キーワード** の4階層で設定でき、
**下の階層の設定が優先されます。** 広告の最終URLだけ変えても、キーワードに個別設定が残っていると
そちらが使われます。

1. 各広告の「最終ページURL」を `https://en1150.co.jp/lp1/` に変更
2. **キーワードの最終URLに個別設定が残っていないか確認**（残っていれば同じURLへ、または空にする）
3. 広告表示オプション（サイトリンク等）は**そのまま**。公式サイトの各ページへ送る導線として機能します

### 3-4. トラッキングテンプレート

`gclid` / `utm_*` を LP側で保存する実装（v0263）を活かすため、
**アカウント設定の「トラッキング テンプレート」**を確認してください。

推奨値（**現在の設定は未確認**。既存があれば上書きせず、内容を確認してから判断してください）：

```
{lpurl}?utm_source=google&utm_medium=cpc&utm_campaign={campaignid}&utm_content={adgroupid}&utm_term={keyword}
```

`gclid` は自動タグ設定（auto-tagging）がONなら Google が自動で付与します。**ON かどうかを確認してください。**

⚠ トラッキングテンプレートの変更はアカウント全体に影響します。既存設定がある場合は、
変更前に現在の値を控えてください。

### 3-5. 変更後

- 広告は**再審査**に入ります（通常は数時間〜1営業日）。この間は配信が止まる場合があります
- 審査通過後、実際に `/lp1/` に着地するかを広告プレビューで確認してください

## 4. 切替前に記録するベースライン（これが無いと比較できません）

Google広告の管理画面で、**切替対象の広告グループについて直近30日**の以下を控えてください。

| 指標 | 用途 |
|---|---|
| 表示回数・クリック数・CTR | 広告側の変化を切り分ける |
| 費用・平均CPC | コスト比較 |
| コンバージョン数・CPA | **判定の本命** |
| 平均掲載順位／インプレッションシェア | 入札環境の変化を切り分ける |

GA4側（`/kaiyou-sou/` 直近30日・`country = Japan`）：

| 指標 | 用途 |
|---|---|
| 広告経由セッション | 母数 |
| `contact_submit` / `tel_click` / `line_click` | CV |
| 平均エンゲージメント時間・スクロール | 補助指標（**これだけで勝敗を決めない**） |

**判定はCV数とCPAで行い、CVが合計10件たまるまで結論を出しません。**
エンゲージメント率や滞在時間は、回遊型（`/kaiyou-sou/`）とLP型（`/lp1/`）で意味が違うため、単独では使いません。

なお `/kaiyou-sou/` の自然検索は直近で月5セッション規模のため、**広告を外しても自然流入への影響はありません**
（広告流入はSEO評価と無関係です）。
