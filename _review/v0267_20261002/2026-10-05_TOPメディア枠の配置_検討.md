## 0. 結論

**移動には賛成です。ただし「移動だけ」では効果が出ません。**

理由：この枠は**中身に未解決の問題を2つ抱えたまま**です（仮文字が本番に出ている／媒体名が3ページで食い違っている）。
位置を変えても、その2つはそのまま残ります。

**提案は「下に移す」ではなく「下にある『セミナー・活動実績』へ統合する」です。**

## 2. 同感できる点

【事実】メディア枠は上から3番目で、「縁が選ばれる理由」と「こんなお悩みはありませんか？」の**あいだに割り込んでいます。**

【仮説】供養の検索者は、まず「自分の状況でも頼めるのか」を確認します。
「遠方に住んでいる」「親族が反対している」「費用がどれくらいか」——これらが扱われているかを探す段階で、
事業者側の実績を見せられても判断材料になりません。

いまの順序は

```
FV → 選ばれる理由 → メディア実績 → お悩み → サービス
      （自社の話）  （自社の話）    （やっと訪問者の話）
```

**自社の話が2つ続いてから、ようやく訪問者の悩みに触れています。** ここを詰めたいという感覚は妥当です。

【期待効果】「お悩み → サービス → 流れ」が連続することで、訪問者が自分の状況を当てはめながら読み進められます。

## 3. 批判する点（根拠つき）

### ① 移動しても、仮文字は本番に出続けます

`index.php` 1102行の「MBCラジオ『○○の時間』」は、**2026-09-21に報告してから2週間、本番に出たままです。**
下に移せば目立たなくなりますが、見られていないだけで、消えてはいません。

### ② 媒体名が3ページで食い違っています（未確認）

| ページ | 記載 |
|---|---|
| TOP | NHK「あさイチ」「シブ5時」「NHKスペシャル」 |
| `/grave/` | MBC南日本放送・KKB鹿児島放送・KTS鹿児島テレビ・KYT鹿児島読売テレビ（鹿児島の民放4局） |
| `/seizen/` | リンク先がFBS福岡放送（`news.ntv.co.jp/n/fbs/…`） |

TOPのNHK3番組は、`/grave/` の一覧にも構造化データにも含まれていません。**どれが事実か未確認のままです。**

### ③ 下に移すと、弱い枠がさらに弱くなります

いまのメディア枠は「媒体名だけ」で、年月も内容もありません。上にあるから目に入っているだけで、
**下に移せばほぼ読まれません。**「位置を下げる」は、この枠に関しては「実質的に消す」に近い判断になります。

消していいなら消す、残すなら強くする。**どちらかに決めるべきで、中間の「下げる」が一番もったいない**と考えます。

### ④ 実績系のセクションが2か所に分散しています

3番目にメディア枠、14番目にセミナー・活動実績。どちらも「信頼の証明」です。
分けている理由がなく、**1か所にまとめた方が読み手にも分かりやすく、保守も楽になります。**

### ⑤ （別件ですが）「選ばれる理由」が2つあります

2番目「縁が選ばれる理由」と10番目「縁が選ばれる6つの理由」。見出しがほぼ同じで、訪問者には重複に見えます。
今回の移動とは別に、整理の対象です。

## 4. 提案

### 案A（推奨）｜統合する

メディア枠を**14番目「セミナー・活動実績」に統合**し、セクション名を「メディア掲載・活動実績」に変更。

```
FV → 選ばれる理由 → お悩み → サービス → 流れ → ギャラリー
   → 代表ごあいさつ → お客様の声 → 6つの理由 → 比較 → 対応エリア
   → ★メディア掲載・活動実績（統合）→ FAQ → ブログ → CTA
```

- 実績が1か所に集まり、情報量で説得力が出ます
- メディア掲載も**年月＋媒体名＋内容の一行**の形式に揃えられます（活動実績と同じ形式）
- 事実確認が取れた媒体だけを載せられます

### 案B｜最終CTAの直前に置く

実績は「頼もうか」と考え始めた瞬間に効きます。**17番目のCTAの直前**が最も効く位置という考え方もあります。
ただしこの位置には既にFAQとブログがあり、順序の再設計が必要です。工数は案Aより大きくなります。

### 案C｜小さく上に残す

2番目「選ばれる理由」の中に、**1行のテキスト列**として吸収します（アイコン3つの枠はなくす）。
「MBC南日本放送・KKB鹿児島放送ほかで紹介されました」程度。上に残しつつ、流れを分断しません。

## 7. 別の視点から

### 「どこに置くか」より「何を書くか」

メディア掲載は、**媒体名だけでは効きません。**「NHK」と書いてあっても、訪問者は
「何を取り上げられたのか」が分からないと判断に使えません。

効く形：

```
2026年3月  MBC南日本放送「◯◯」
          お墓じまいの最新事情として、鹿児島の離島対応を取材いただきました
```

年月・番組名・内容の一行。これがあれば、置く位置は下でも効きます。**逆に媒体名だけなら、上に置いても効きません。**

### 第三者の裏づけリンクが最強

`/seizen/` は放送局のニュース記事へリンクしています。これは第三者による証明として最も強い形です。
**他の媒体についても、公式サイトやTVerの該当ページへのリンクを探してください。**

### 測ってから決める方法

スクロール深度の計測があれば、下に移した場合の到達率を事前に推定できます。
ただし**現状、スクロール深度の計測は見つかりませんでした（未確認）。** GA4で入れるなら30分程度です。

## 8. 自己検証（この見立てが外れているとしたら）

**堤様が「メディア掲載を最大の武器にしたい」と考えており、営業上の要望として上に置いている場合です。**

その場合、牧瀬様の「下げたい」という判断と堤様の意向が衝突します。先に意向を確認してください。
衝突する場合は、位置ではなく**中身の具体化（年月・番組名・内容）で、上に置く価値を作る**方向が落としどころになります。

もう一つの可能性は、**メディア枠がすでにクリックされており、下げると実害が出る場合**です。
ただしこの枠にはリンクがないため、クリック実績そのものが存在しません。この線は薄いと考えています。

## 9. この方針が外れていた場合の代替ルート

**統合も移動もせず、メディア枠をその場で「1行のテキスト列」に縮める（案C）。**
セクション1つ分の縦の長さが消えるため、「お悩み」までの距離は短くなります。
移動に伴う順序の再検討が不要で、変更が最小。事実確認が済んでいない段階でも実行できます。
