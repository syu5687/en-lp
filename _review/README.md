# _review フォルダについて

サイトのレビュー資料・実装計画書を **バージョンごとのフォルダ**に分けて保存しています。

```
_review/
├── README.md                  ← このファイル
├── v0256_20260902/            ← v20260713-0256 時点
└── v0257_20260903/            ← v20260713-0257 時点（最新）
```

フォルダ名は `v<APP_VERSIONの下4桁>_<作成日 YYYYMMDD>` です。
`APP_VERSION` は `includes/config.php` の11行目、同じ値が `VERSION` ファイルにも入っています。
